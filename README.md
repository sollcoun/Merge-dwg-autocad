# MergeCAD

Инструмент для объединения нескольких DWG-файлов в один результирующий чертёж через COM-интерфейс AutoCAD.

MergeCAD открывает каждый исходный DWG-файл средствами AutoCAD и копирует все объекты (геометрию, блоки, слои, типы линий, текстовые стили и т. д.) из Model Space — и, опционально, из Paper Space — в один общий итоговый файл. Копирование выполняется без смещения и без трансформации координат, то есть является программным эквивалентом ручной вставки «с исходными координатами».

## Возможности

- Объединение произвольного количества DWG-файлов в один
- Добавление файлов целой папкой или по отдельности
- Включение/выключение отдельных файлов без удаления из списка
- Опциональное копирование Paper Space (листов/компоновок)
- Режим со скрытым или видимым окном AutoCAD во время обработки
- Журнал выполнения и отчёт об ошибках по каждому файлу
- Индикатор прогресса и возможность остановить процесс
- Есть графический интерфейс (GUI) и вариант для запуска из командной строки

## Требования

- Windows
- Установленный AutoCAD (любая современная версия с поддержкой COM/ActiveX)
- Python 3.x (если запускать из исходников, а не из готового `.exe`)
- Зависимости: `pywin32`, `tqdm` (для CLI-версии)

```bash
pip install pywin32 tqdm
```

## Установка

### Вариант 1 — готовый установщик

Скачайте и запустите `MergeCAD_Setup_v1.0.0.exe` из раздела релизов.

### Вариант 2 — запуск из исходников

```bash
git clone https://github.com/<ваш-аккаунт>/MergeCAD.git
cd MergeCAD
pip install pywin32 tqdm
python merge_dwg_gui.py
```

## Использование

### Графический интерфейс

```bash
python merge_dwg_gui.py
```

1. Добавьте DWG-файлы через кнопку «Выбрать папку...» или «Добавить файлы...».
2. При необходимости отключите ненужные файлы галочкой в списке.
3. Укажите путь к результирующему файлу в поле «Результат».
4. При необходимости включите опции «Paper Space» и «Показывать окно AutoCAD».
5. Нажмите «Объединить» и дождитесь завершения.

Подробная пошаговая инструкция для пользователей — в файле [`MergeCAD_Instruktsiya.docx`](./MergeCAD_Instruktsiya.docx).

### Командная строка

```bash
python merge_dwg_com.py --source "C:\Projects\All" --output "C:\Result\merged.dwg"

python merge_dwg_com.py --source "C:\Projects\All" --output "C:\Result\merged.dwg" ^
    --template "C:\Templates\acadiso.dwt" --paperspace --visible
```

| Аргумент | Описание |
|---|---|
| `--source` | Папка с исходными DWG-файлами |
| `--output` | Путь к результирующему DWG-файлу |
| `--template` | (опционально) DWT-шаблон для нового чертежа |
| `--paperspace` | Копировать также Paper Space (листы) |
| `--visible` | Показывать окно AutoCAD во время работы |

## Важно знать

- **Система координат.** Все исходные файлы должны использовать одну и ту же систему координат и единицы измерения — иначе объекты после объединения могут «наложиться» друг на друга не на своих местах. Это ожидаемое поведение при копировании без смещения, а не ошибка программы.
- **Внешние ссылки (XREF).** Копируются как ссылки на исходный путь. Если нужно, чтобы содержимое xref физически вошло в результат, выполните `XREF BIND` в исходном файле перед объединением.
- **Однопоточность AutoCAD (STA COM-сервер).** Во время автоматизации возможны отклонённые вызовы (`RPC_E_CALL_REJECTED`) — это нормально при интенсивной работе с COM; программа автоматически повторяет такие вызовы.

## Сборка исполняемого файла

Проект собирается через PyInstaller:

```bash
pyinstaller MergeCAD.spec
```

Установщик для конечных пользователей собирается через Inno Setup на основе `MergeCAD.iss`.

## Структура проекта

```
merge_dwg_com.py     — логика объединения через AutoCAD COM (ядро + CLI)
merge_dwg_gui.py      — графический интерфейс (использует merge_dwg_com)
MergeCAD.spec         — конфигурация сборки PyInstaller
MergeCAD.iss          — скрипт сборки установщика (Inno Setup)
MergeCAD.ico          — иконка приложения
```
