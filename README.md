# MergeCAD

Инструмент для объединения нескольких DWG-файлов в один результирующий чертёж через COM-интерфейс AutoCAD.

MergeCAD открывает каждый исходный DWG-файл средствами AutoCAD и копирует все объекты (геометрию, блоки, слои, типы линий, текстовые стили и т. д.) из Model Space — и, опционально, из Paper Space — в один общий итоговый файл. Копирование выполняется **без смещения и без трансформации координат**, то есть является программным эквивалентом ручной вставки «с исходными координатами».

Дополнительно программа умеет автоматически находить и вставлять растровые изображения с привязкой (пары `картинка.bmp` + `картинка.bpw`) сразу в правильное место, масштаб и поворот.

## Возможности

### Объединение чертежей
- Объединение произвольного количества DWG-файлов в один
- Добавление файлов целой папкой или по отдельности
- Drag-and-drop папок и файлов прямо в окно программы
- Включение/выключение отдельных файлов галочкой
- Массовое снятие/установка галочек для выделенных файлов (как в проводнике)
- Опциональное копирование Paper Space (листов/компоновок)
- Режим с видимым или скрытым окном AutoCAD

### Изображения с привязкой
- Автоматический поиск пар BMP + BPW в выбранной папке
- Вставка растровых подложек сразу с правильными координатами, масштабом и поворотом
- Не нужно вручную указывать точку вставки

### Интерфейс
- Современный тёмный дизайн
- Выпадающие настройки (под кнопкой «Настройки»)
- Журнал выполнения с возможностью скрыть
- Индикатор прогресса
- Возможность остановить процесс
- Автоматический Zoom Extents после объединения (чертёж сразу показывается целиком)
- Если путь сохранения не указан — результат сохраняется на Рабочий стол

### Два способа запуска
- Графический интерфейс (GUI)
- Командная строка (CLI)

## Требования

- **Windows**
- Установленный **AutoCAD** (любая современная версия с поддержкой COM/ActiveX)
- Python 3.8+ (если запускать из исходников)
- Зависимости:

```bash
pip install pywin32 tqdm
```

Опционально (для drag-and-drop):

```bash
pip install windnd
```

## Использование

### Графический интерфейс

```bash
python merge_dwg_gui.py
```

1. Добавьте DWG-файлы:
   - кнопкой **«Папка»** — все `.dwg` из выбранной папки
   - кнопкой **«Файлы»** — отдельные файлы
   - или просто **перетащите** папку/файлы в окно
2. При необходимости снимите галочки с ненужных файлов  
   (можно выделить несколько через `Ctrl` / `Shift` и снять галочку сразу у всех)
3. Откройте **«Настройки»** (кнопка справа вверху):
   - укажите, куда сохранить результат  
     *(если поле пустое — сохранится на Рабочий стол как `merged.dwg`)*
   - включите нужные опции:
     - Листы (Paper Space)
     - Показывать окно AutoCAD
     - Вставлять картинки (BMP+BPW)
     - Показывать журнал
4. Нажмите **«Объединить»** и дождитесь завершения
5. После окончания чертёж автоматически масштабируется (Zoom Extents)

### Командная строка

```bash
python merge_dwg_com.py --source "C:\Projects\All" --output "C:\Result\merged.dwg"

python merge_dwg_com.py --source "C:\Projects\All" --output "C:\Result\merged.dwg" ^
    --template "C:\Templates\acadiso.dwt" --paperspace --visible
```

| Аргумент | Описание |
|----------|----------|
| `--source` | Папка с исходными DWG-файлами |
| `--output` | Путь к результирующему DWG-файлу |
| `--template` | (опционально) DWT-шаблон для нового чертежа |
| `--paperspace` | Копировать также Paper Space (листы) |
| `--visible` | Показывать окно AutoCAD во время работы |
| `--hidden` | Скрыть окно AutoCAD |
| `--no-images` | Не искать и не вставлять пары BMP+BPW |
| `--log` | Путь к файлу лога |

## Важно знать

- **Система координат.**  
  Все исходные файлы должны использовать одну и ту же систему координат и единицы измерения. Иначе объекты после объединения могут «наложиться» не на своих местах. Это ожидаемое поведение при копировании без смещения.

- **Внешние ссылки (XREF).**  
  Копируются как ссылки на исходный путь. Если нужно, чтобы содержимое xref физически вошло в результат, выполните `XREF BIND` в исходном файле перед объединением.

- **Растровые изображения.**  
  Программа ищет пары `имя.bmp` + `имя.bpw`. Если `.bpw` нет — картинка пропускается (без привязки корректно разместить её нельзя).

- **Однопоточность AutoCAD.**  
  AutoCAD — STA COM-сервер. Во время автоматизации возможны временные отказы (`RPC_E_CALL_REJECTED`). Программа автоматически повторяет такие вызовы.

## Сборка

### Исполняемый файл (PyInstaller)

```bash
pyinstaller MergeCAD.spec
```

Сборка установщика для конечных пользователей — через `MergeCAD.iss`.

MergeCAD.spec      — конфигурация сборки PyInstaller
MergeCAD.iss       — скрипт установщика (Inno Setup)
MergeCAD.ico       — иконка приложения
